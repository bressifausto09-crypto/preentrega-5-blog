Blog de Consola en Python

Descripcion

Este proyecto es un blog de consola desarrollado en Python. Permite listar publicaciones, buscar por titulo, filtrar por etiquetas y validar los datos de cada publicacion.

Estructura del proyecto

* main.py: inicia el programa.
* blog/datos.py: contiene los datos del autor, los estados, las etiquetas y las publicaciones.
* blog/menu.py: muestra el menu interactivo.
* blog/operaciones.py: contiene las funciones para listar, buscar y filtrar publicaciones.
* blog/validaciones.py: verifica que las publicaciones tengan los campos obligatorios y los tipos de datos correctos.
* blog/__init__.py: identifica la carpeta como un paquete de Python.

Requisitos

Tener Python 3 instalado.

Como ejecutar el programa

1. Abrir una terminal en la carpeta principal del proyecto.
2. Ejecutar el siguiente comando:

python main.py

Funcionalidades

1. Listar todas las publicaciones.
2. Buscar publicaciones por titulo.
3. Filtrar publicaciones por etiqueta.
4. Validar las publicaciones y mostrar errores cuando faltan datos.
5. Salir del programa.
